  1. Missing opencv-python (cv2) in Python 3.12:
      • On the other box, the Python environment had OpenCV installed.
      • On this box, start_wyze_viewer.bat had hardcoded
      C:\Python\Python312\python.exe.
      • C:\Python\Python312 did not have cv2 installed
      (ModuleNotFoundError: No module named 'cv2'), which immediately
      caused wyze_server.py to drop every stream worker into an offline
      error state.
      • Resolution applied: Installed opencv-python into both the
      workspace virtual environment (python.exe) and
      C:\Python\Python312\python.exe. Also updated
      start_wyze_viewer.bat to detect and use the active venv and
      Python 3.13 first.
  2. Windows Defender Firewall Port Requirements:
      • Port 5005 (TCP): Inbound web access for the Multi-Cam Viewer
      dashboard from LAN devices.
      • Port 322 (TCP): Wyze TLS RTSPS camera stream ingest.
      • Port 554 (TCP/UDP): Standard RTSP camera streaming.
      • Port 8554 / 8555 (TCP/UDP): Alternate RTSP ports (docker-wyze-
      bridge / go2rtc / wz_mini_hacks).
      • Ports 10001, 10002 (UDP): Wyze LAN discovery broadcast & TUTK
      P2P session negotiation.
      • Ports 10000–65535 (UDP): Dynamic UDP RTP return packets for
      video/audio streams.
      • Ports 1935, 5000, 8443, 8888, 8889 (TCP/UDP): Wyze Bridge
      WebRTC, RTMP, and HLS protocols.
      • Application Rules: Allowing incoming and outgoing traffic for
      python.exe.

            $params = @{
                Name        = $rule.Name
                DisplayName = $rule.DisplayName
                Description = $rule.Description
                Direction   = $rule.Direction
                Action      = "Allow"
                Enabled     = "True"
                Profile     = "Any"
            }

            if ($rule.Protocol -eq "TCP,UDP") {
                foreach ($proto in @("TCP", "UDP")) {
                    $subName = "$($rule.Name)-$proto"
                    $subDisp = "$($rule.DisplayName) [$proto]"
                    $subParams = $params.Clone()
                    $subParams["Name"] = $subName
                    $subParams["DisplayName"] = $subDisp
                    $subParams["Protocol"] = $proto
                    if ($rule.ContainsKey("LocalPort"))  {
  $subParams["LocalPort"]  = $rule.LocalPort }
                    if ($rule.ContainsKey("RemotePort")) {

  SilentlyContinue

                        Rule      = $subDisp
                        Direction = $rule.Direction
                        Protocol  = $proto
                        Port      = if ($rule.ContainsKey("LocalPort"))
  { "Local: " + ($rule.LocalPort -join ',') } else { "Remote: " +
  ($rule.RemotePort -join ',') }
                        Status    = "Active / Allowed"
                    }
                }
                continue
            } else {
                $params["Protocol"] = $rule.Protocol
                if ($rule.ContainsKey("LocalPort"))  {
  $params["LocalPort"]  = $rule.LocalPort }
                if ($rule.ContainsKey("RemotePort")) {
  $params["RemotePort"] = $rule.RemotePort }

  1. Firewall & Environment Setup:
      • Generated open_wyze_firewall_ports.ps1 and
      open_wyze_firewall_ports.bat (self-elevating) to unblock all RTSP,
      RTSPS (port 322), UDP discovery (10001/10002), and streaming

      prioritize the virtual environment's Python interpreter.
  2. Automated Motion Detection & Pre-Roll Ring Buffer:
      • In wyze_server.py, an ultra-lightweight background motion
      detector evaluates downsampled grayscale deltas (<0.5 ms/frame).
      • An 80-frame (~4s) memory ring buffer runs continuously,
      capturing the moments before motion is triggered into the
      recording.
      • Saves clips with mp4v codec and captures high-resolution .
      thumb.jpg thumbnails asynchronously without stuttering live RTSP
      ingestion.
  3. Quota & Hard Drive Storage Management:
      • In wyze_server.py, clips are indexed into
      recordings/recordings_index.json.
      • Configurable Hard Quota (default 5.0 GB): Enforces automatic
      FIFO purge (oldest recordings deleted first) whenever usage
      crosses 90% of the quota.
      • Retention Period (default 7 days, 0 = disabled): Automatically
      purges stale clips.
      • Real-time hard drive free space and quota telemetry reported to
      the UI.
  4. Web UI Gallery & Controls:
      • Recordings Gallery Modal: Accessible from the top navigation
      bar with a live recording counter badge. Displays thumbnails,
      camera badges, duration, trigger type (Motion / Manual), and file
      size.
      • Video Player: HTML5 <video> player with Range-seeking support
      and universal MJPEG frame-scrubber fallback.
      • Per-Camera Manual Record Button (🔴 Record 30s): Available on
      both the Birdseye NOC grid and single-camera subwindows.
      • Live Indicators: Dynamic ● REC (pulsing red) and ● MOTION
      (amber) badges on each camera feed.
      • Settings Modal (⚙ Recording Quota): Adjust motion sensitivity
      (Low / Medium / High), clip length (15s–120s), storage quota (GB),
      and retention days directly from the web browser.
      • Maintenance Tools: Single clip delete or bulk purge options
      ("Delete All" or "Delete Older than N Days").
